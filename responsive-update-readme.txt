ECON Kitchen - Responsive Update

Updated: 06 Oct 2026

What was added:
- assets/css/responsive-master.css
- viewport meta tag on every full HTML document where missing
- responsive stylesheet injected into all full HTML pages

Target breakpoints:
- Small mobile: <= 479px
- Mobile: <= 767px
- Tablet: <= 991px
- Tablet/small laptop: <= 1199px
- Desktop: 1200px+
- Large desktop: 1440px+

Core improvements:
- fluid typography
- responsive containers
- grids collapse 2 -> 1 columns
- image/video/iframe overflow protection
- form and input width protection
- table horizontal scrolling support
- sticky action viewport protection
- pills/tabs mobile horizontal scrolling
- footer stacking
- fixed-width defensive safeguards
- no horizontal body overflow

Original files and functionality are preserved; responsive-master.css is an override layer.
